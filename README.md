# Chat Reader

一个 Chrome 扩展，把 [Claude](https://claude.ai) 网页版的聊天页面变成一本**可以批注的教材**：调排版、看目录、划线写批注、汇总成笔记。

## 功能

**排版**（点扩展图标，在弹窗里调，实时生效）
- 正文字体、代码字体分开设置，自动检测字体是否已安装
- 字号、行距、字间距、段落间距、对话区宽度、公式缩放
- 背景色调：浅色 / 深色模式各 3 种护眼色调，跟随 Claude 主题自动切换
- 3 套可命名的预设，一键切换

**目录**（页面右侧浮动面板）
- 列出整段对话里的每一次提问，点击平滑跳转并闪烁提示（还没加载的旧消息会自动加载）
- 滚动时自动高亮当前所在的提问，显示阅读进度
- 有标注的提问旁显示小圆点
- 回到顶部 / 底部；快捷键 `Alt+M` 展开或收起；面板展开时正文自动让位，不被遮挡

**标注**
- 选中文字后弹出工具栏：5 种颜色高亮、波浪线、批注；Claude 的回复和自己的提问都能标
- 点击已有标注可以改颜色、改样式、编辑批注、删除
- 刷新、滚动、切换对话后自动还原；原文找不到时（编辑过提问、重新生成了回复）标记为"失效"，原文和批注都保留
- 面板里的「标注」标签页：按颜色筛选，点击跳回原文

**我的笔记**（扩展内的独立页面）
- 按对话汇总所有标注，可搜索、编辑批注、删除、清理失效标注
- 一键复制为 Markdown（方便粘贴到 Obsidian）
- 导出 / 导入 JSON 备份，定期提醒备份

**适配状态自检**：弹窗里逐项显示页面关键元素是否找到。Claude 网站改版导致失效时，一眼就能看出是哪里坏了。

## 安装

本扩展没有上架 Chrome 商店，需要用开发者模式加载：

1. 下载本仓库（右上角 Code → Download ZIP，然后解压；或者 `git clone`）
2. Chrome 地址栏打开 `chrome://extensions`，右上角打开**开发者模式**
3. 点**加载已解压的扩展程序**，选择解压出来的文件夹
4. 打开或刷新 claude.ai 的对话页面

更新代码后，在 `chrome://extensions` 里点扩展卡片上的 ↻，再刷新 claude.ai 页面即可。

字体需要先安装在电脑上才能选用，弹窗里会标出哪些已安装。

## 隐私

- 所有设置和标注只存在你本机的 Chrome 里（排版设置随 Chrome 账号同步，标注不同步），不上传到任何服务器。
- 为了让目录能列出整段对话（Claude 只把屏幕附近的消息放在页面里），扩展会在 claude.ai 页面内读取 Claude 网页自己使用的对话接口，用的是你已登录的身份，数据不离开浏览器。
- 只申请了 `storage`、`unlimitedStorage` 两项权限，只在 `claude.ai` 上运行。

## 实现要点

- Manifest V3，纯 JavaScript + CSS，不需要构建工具。
- **站点适配层**：所有和 Claude 页面结构有关的选择器都集中在 [`content/adapters/claude.js`](content/adapters/claude.js)，网站改版时只需要改这一个文件。
- **不修改 Claude 的页面元素**：排版用注入的 CSS；高亮用 [CSS Custom Highlight API](https://developer.mozilla.org/docs/Web/API/CSS_Custom_Highlight_API)；面板、工具栏放在 Shadow DOM 里。
- 标注定位参考 W3C Web Annotation 的 TextQuoteSelector（原文 + 前后文 + 位置提示）。
- 每个功能独立开关、独立出错，任何功能出问题都不影响 Claude 本身使用。

## 目录结构

```
manifest.json          扩展清单
background.js          后台：快捷键、打开"我的笔记"
shared/                弹窗、页面、笔记页共用：默认设置、标注存储
content/
  core/                公共部件：页面监听、设置、功能开关、对话数据、右侧面板、文字定位
  adapters/claude.js   claude.ai 适配层（所有选择器都在这里）
  features/            排版、目录、标注
popup/                 扩展弹窗
notes/                 "我的笔记"页
```
